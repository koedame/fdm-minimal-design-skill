fdm-minimal-design

ModelsGitHub

An agent skill for designing minimalist objects for FDM 3D printing: large radii in plan with sharp edges, a grid, achromatic colours with a single accent, and one shape repeated.

Advise

On an object you model yourself: grid, proportions, radii, chamfers, print orientation and part split, with numbers.

Build

3D models in CadQuery: an STL per part in print orientation, a coloured STEP assembly, previews and a 3D viewer.

Review

A fixed procedure: a table of reasons for every dimension, Dos and Don'ts, use cases, numeric checks and a rendering.

Install in Claude Code

git clone __REPO__.git
cp -r fdm-minimal-design-skill/skills/fdm-minimal-design ~/.claude/skills/

Install in Claude.ai

  1. Download fdm-minimal-design.skill from the releases.
  2. Turn on code execution in Settings → Capabilities.
  3. Upload the file in Customize → Skills.

Details, requirements and the source are on GitHub.
